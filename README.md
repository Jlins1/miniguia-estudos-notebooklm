# 🌳 Miniguia de Estudos: Árvore de Decisão com Python

## 🎯 Contexto e Objetivos

Este projeto foi desenvolvido como parte de um desafio da DIO, utilizando a Inteligência Artificial como ferramenta de aprendizagem ativa.

O tema escolhido para o Caderno Temático foi **Árvore de Decisão (Decision Tree)**, um algoritmo de Machine Learning utilizado principalmente em problemas de classificação e regressão.

A escolha do tema está relacionada aos meus estudos em Análise e Desenvolvimento de Sistemas (ADS) e ao meu interesse pelas áreas de Dados e Inteligência Artificial.

### Objetivos

- Compreender o conceito de Machine Learning;
- Entender o funcionamento de uma Árvore de Decisão;
- Identificar os principais componentes de uma árvore;
- Diferenciar classificação e regressão;
- Conhecer as vantagens e limitações do algoritmo;
- Aprender a utilizar Árvores de Decisão com Python;
- Utilizar o NotebookLM como ferramenta de aprendizagem;
- Desenvolver prompts para facilitar os estudos;
- Organizar o conhecimento adquirido em um material de consulta.
